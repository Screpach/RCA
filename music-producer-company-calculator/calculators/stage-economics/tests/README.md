# Автоматические тесты

Запуск из корня проекта:

```bash
python tests/run_tests.py
```

Нужны Python 3, Chromium и пакет `playwright` для Python. Тест загружает локальные HTML/CSS/JavaScript-файлы непосредственно в Chromium; интернет и web-сервер не требуются.

Покрываются три режима аренды, округление вверх до €0,10, K=1 и K=1,25, пустые поля, очень большие суммы без скрытого clamp, ручная цена, disabled-поля, календарные дни, нулевая посещаемость, отсутствие конечного решения hotelling/безубыточности, правило «все положительные + 12 отрицательных», сортировка, MCDA-импорт и все 25 Plotly-панелей без `NaN`/`Infinity`.
