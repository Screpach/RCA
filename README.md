# Stage Economics — калькулятор спектакля / концерта

Статический webapp без сервера. Откройте `index.html` в браузере или разместите папку на любом static hosting.

## Что реализовано

- Выбор даты концерта через календарь. Количество дней до события рассчитывается автоматически и используется для стоимости рекламной кампании.
- Три режима аренды: всё включено с IVA 21%, всё включено без IVA, только зал без IVA (`/ 0,66 × 1,21`).
- Вместимость 10–30 000 мест и аренда €50–€200 000.
- Маркетинг: месячная ставка агентства пропорционально дням и дневной digital-бюджет; отдельные переключатели IVA 21%.
- Гонорары артистов, репетиции, дополнительный пакет расходов.
- Hotelling 0–33% от цены билета без билетного IVA; итеративный расчёт формульной цены.
- Формула финального brutto:
  `Direct + roundup_0.1((0.03025 × Direct + 1.4641) / 1.06975)`.
- Все денежные затраты округляются вверх до €0,10.
- Динамическая безубыточная цена с билетным IVA, Ticketmaster, загрузкой и вкладом напитков.
- Коэффициент `K = чистая выручка / прямые расходы`:
  - `K < 1` — отрицательный результат;
  - `K = 1` — безубыточная основа;
  - `K ≥ 1,25` — идеальный уровень.
- Рекомендации для каждой загрузки показывают отдельно цену `K = 1` и цену `K = 1,25`.
- 216 аналитических сценариев: 6 цен × 6 загрузок × 3 уровня гонорара × 2 уровня пакета.
- В основной таблице выводятся все положительные сценарии и только 12 отрицательных сценариев с минимальным уходом в минус.
- Фильтры применяются до отбора 12 лучших отрицательных сценариев.
- CSV-экспорт содержит текущий отбор таблицы и дату концерта.
- 24 аналитических модуля и 25 отдельных Plotly-панелей с ленивым рендерингом по мере прокрутки.
- PNG-экспорт из панели Plotly, hover, zoom, pan, легенды. Выбор через график ограничен положительными и 12 лучшими отрицательными сценариями.
- Сохранение параметров в `localStorage`.

## Принятые трактовки

1. Работа рекламщиков за период: `месячная ставка с IVA × дни до концерта / 30`.
2. Hotelling в основном формульном расчёте: процент от формульной цены билета без билетного IVA × полная вместимость. Из-за циклической зависимости применяется итерация до сходимости.
3. В сценариях hotelling зависит от фактически проданных билетов.
4. Формульная цена и динамическая цена `K = 1` показываются отдельно. Динамическая цена учитывает вычет билетного IVA и Ticketmaster.
5. Чистый вклад напитка — дополнительный доход после его себестоимости; он используется только в сценарной аналитике.
6. Дополнительный пакет расходов добавлен, поскольку он необходим для требуемых heatmap и сценарного фактора.
7. Полные 216 сценариев остаются базой аналитических графиков. Ограничение «все положительные + 12 лучших отрицательных» применяется к таблице, CSV и выбору текущего сценария.

## MCDA

Исходная матрица 25×25 в задании не приложена. Поэтому две MCDA-панели используют прозрачный live-proxy: 25 детерминированных наборов весов для остатка, маржи, посещаемости, запаса прочности и обратных прямых расходов. Это не представляется как исходный рейтинг. Для подключения оригинальной матрицы замените `MCDA_WEIGHT_RUNS` в `app.js`.

## Запуск

```bash
python -m http.server 8080
```

Затем откройте `http://localhost:8080` из папки проекта.

Plotly включён локально в `plotly.min.js`, поэтому интернет для графиков не требуется.
